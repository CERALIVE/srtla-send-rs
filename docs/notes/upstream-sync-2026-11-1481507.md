## Follow-ups

- Measure `current_thread` and the system allocator on the RK3588 device. Upstream's
  numbers are from loopback on a desktop host; `scripts/bench-loopback.sh` was not run.
- Upstream `602c49e` adds a `deslop-please` architectural lint to CI. The fork CI does
  not run it; adopting it means a pinned, checksummed tool download in `ci.yml`.
- Upstream doc defects to report upstream: `docs/EXTENDED_KEEPALIVE.md` still links
  `crates/srtla-protocol/src/builders.rs`, which `4aeba78` removed, and
  `crates/srtla-core` doc comments still name `SrtlaConnection::note_sent`, which no
  longer exists. Both are kept as upstream wrote them.
- `scripts/netns_test_gate.sh` does not register `netns_arrival_reports`, added in the
  `8677bb49` sync, so the gate script never runs it. It also runs each target's tests in
  parallel threads, while `crates/network-sim/src/harness.rs` names the veth pairs after
  the process id alone (`vs{pid:x}_{i}`), so sibling tests collide on `ip link add`. Pass
  `--test-threads=1` as upstream CI does, or name the pairs per test.
- `ci/build-deb.sh` depends on the caller's umask: under 0077 its control directory is
  0700 and `dpkg-deb` refuses it. Creating the directory with an explicit mode would
  make local packaging independent of it.
- The follow-ups in the `8677bb49` ledger still apply.
